# Simple Interest Calculator

A beginner-friendly web application that calculates simple interest and the total amount using principal, annual interest rate, and time in years.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

**Total Amount = Principal + Simple Interest**

## Features

- Calculates simple interest instantly
- Displays the final amount (principal + interest)
- Accepts decimal values
- Validates inputs and displays helpful error messages
- Formats results as Indian Rupees (INR)
- Responsive layout for mobile and desktop
- Built with plain HTML, CSS, and JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enter the principal amount, annual interest rate, and time in years.
4. Select **Calculate Interest**.

No installation or external dependencies are required.

## Example

For a principal of ₹10,000, an annual rate of 5%, and a time period of 2 years:

- Simple Interest = (10,000 × 5 × 2) / 100 = ₹1,000
- Total Amount = ₹10,000 + ₹1,000 = ₹11,000
