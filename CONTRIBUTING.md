# Contributing

Thank you for your interest in contributing to the Simple Interest Calculator! All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a branch for your change: `git checkout -b feature/your-change`.
3. Make your changes and test them in a modern web browser.
4. Commit your work with a clear message: `git commit -m "Describe your change"`.
5. Push your branch: `git push origin feature/your-change`.
6. Open a pull request and explain what your change does and why it is useful.

## Reporting Bugs

When opening an issue, please include:

- A clear, descriptive title.
- Steps to reproduce the problem.
- What you expected to happen and what actually happened.
- Your browser and operating system, if relevant.
- Screenshots or error messages, if they help explain the issue.

Please check existing issues first to avoid duplicate reports.

## Suggesting Enhancements and Ideas

Feature suggestions and ideas are welcome. Describe the problem you want to solve, the proposed behavior, and any alternatives you have considered.

## Documentation Improvements

Improvements to spelling, clarity, examples, setup instructions, and project documentation are welcome. Keep explanations accurate and beginner-friendly.

## Code and Review Guidelines

- Keep changes focused and easy to review.
- Use clear, descriptive names and consistent formatting.
- Preserve the calculator's existing functionality.
- Test calculations with normal, decimal, zero-rate, and invalid inputs where relevant.
- Be respectful and constructive in code reviews and discussions.
- Update documentation when behavior or usage changes.

## Questions

If you are unsure where to start, open an issue describing your question or the contribution you would like to make.

By participating in this project, you agree to follow the guidance in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
